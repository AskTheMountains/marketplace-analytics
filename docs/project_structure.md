### **Структура проекта**

Структура проекта организована следующим образом:

```
{marketplace_name}
├── Clients
│   └── {client_name}
│       └── {reports_folder}
└── scripts
    └── {marketplace_scripts}.py
```

- Названия, заключённые в фигурные скобки `{}` (например, `{marketplace_name}`), обозначают переменные директории или файлы, количество и наименования которых могут отличаться в зависимости от клиентов и отчетов.
- Названия без фигурных скобок имеют фиксированное значение и не подлежат изменению.

### **Обозначения**

- **{marketplace_name}** — директория соответствующего маркетплейса (например, `ozon`, `wb`).
    - **Clients** — папка, содержащая директории по клиентам.
        - **{client_name}** — папка конкретного клиента, где хранятся все отчёты, относящиеся к нему.
            - **{reports_folder}** — папка с определённым видом отчёта для данного клиента.
- **scripts** — директория со скриптами Python для формирования отчетов. Здесь также могут располагаться вспомогательные файлы (csv, xlsx, json), используемые в скриптах.

---

### **Пример структуры директорий для клиента**

Рассмотрим пример для клиента `Client_1`, у которого есть доступ к маркетплейсам **Ozon** и **WB**.

<details>
<summary>Структура для Ozon</summary>

```plaintext
ozon
├── Clients/
│   └── Client_1/
│       ├── Actions/
│       │   └── Таблица_по_акциям_Client_1_Ozon.xlsx
│       └── CampaignsReport/
│           └── Отчет_РК_Client_1_Ozon.xlsx
└── scripts/
    ├── create_actions_svod.py
    ├── format_svod_actions.py
    └── create_campaigns_report.py
```
</details>

<details>
<summary>Структура для WB</summary>

```plaintext
wb
├── Clients/
│   └── Client_1/
│       ├── SalesOrdersSvod/
│       │   └── Свод_продажи_Client_1_WB.xlsx
│       └── CampaignsReport/
│           └── Отчет_РК_Client_1_WB.xlsx
└── scripts/
    ├── create_sales_svod.py
    └── create_campaigns_report.py
```
</details>

---

**При добавлении нового клиента и формировании для него отчетов соответствующая структура папок создаётся автоматически.**
**Папка `{marketplace_name}/scripts/` изменяется только при появлении новых скриптов.**
