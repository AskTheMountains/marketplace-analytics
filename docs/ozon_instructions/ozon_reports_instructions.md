## **О разделе**

В этом разделе представлены пошаговые инструкции по формированию различных отчетов для клиентов маркетплейса Ozon.

---

### Отчет «Планирование поставок»

Чтобы сформировать отчет по планированию поставок, выполните следующие действия:

1. Проверьте настройки:
    - Убедитесь, что файл `settings.json` заполнен корректно. [Инструкция](../settings_description/settings_json_description.md).

2. Выберите клиента:
    - Укажите номер нужного клиента в файле `options.py`.

3. Выгрузите данные:
    - Запустите скрипт выгрузки данных через терминал:
    ```  bash
    python.exe -m ozon.scripts.uploadDataFromOzon
    ```
    - Дождитесь окончания процесса. Если заказов много, выгрузка может занять до 2–3 часов.

4. Проверьте успешное завершение выгрузки:
    - По окончании выгрузки появится сообщение:
    ```bash
    DONE UPLOADING FILES FOR CLIENT {client_name}
    ```
    где `client_name` — имя выбранного клиента в `options.py`.

5. Выполните расчет метрик:
    - Запустите расчет метрик командой:
    ```bash
    python.exe -m ozon.scripts.calcMetrics
    ```
    - После завершения появится сообщение о том, что расчет метрик выполнен.

6. Выполните расчет поставок:
    - Запустите расчет поставок командой:
     ```bash
     python.exe -m ozon.scripts.create_supply_svod
     ```
    - После завершения работы скрипта появится сообщение о формировании отчета расчета поставок.

7. Найдите итоговый файл отчета:
    - Готовый отчет располагается по пути:
     ```
     директория_проекта/ozon/Clients/{client_name}/SupplySvod/
     ```
     где `client_name` — имя клиента, выбранного в options.py.

    Маска имени итогового файла:
     ```
     {date_metrics}_Расчет_поставок_{client_name}_Ozon_Formatted.xlsx
     ```
    - date_metrics — дата расчета метрик.
    - client_name — имя клиента.
