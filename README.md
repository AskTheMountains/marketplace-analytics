### Краткое описание
 Проект выгрузки данных и формирования аналитических отчетов по марктеплейсам (Ozon, WB и др.)
### Быстрый старт
1. Клонировать репозиторий
    ```shell
    git clone https://gitlab-dvp.1cbit.ru/bit_consulting/marketplaces.git
    ```
2. Переименовать файл `settings_example.json` в `settings.json`, ввести данные клиента.
3. Переименовать файл `options_example.py` в `options.py` и указать в нем номер клиента, для которого будут формироваться отчеты
4. Запустить нужный скрипт. Более подробные инструкции по использованию скриптов см. на [Wiki](https://gitlab-dvp.1cbit.ru/bit_consulting/marketplaces/-/wikis/home)
