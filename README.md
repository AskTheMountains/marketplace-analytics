# Формирование аналитических отчётов по маркетплейсам (Ozon, WB)

Проект для выгрузки данных и формирования аналитических отчётов по маркетплейсам **Ozon** и **Wildberries (WB)**: своды по заказам и продажам, планирование поставок, участие в акциях, статистика по рекламным кампаниям (РК) и маржинальность. Данные получаются через официальные API маркетплейсов (Seller API и Performance API Ozon, API Wildberries), а также из файлов, выгруженных пользователем из Личного кабинета продавца. Результаты сохраняются в файлы Excel (`.xlsx`).

Есть два способа работы:

- **Автономные скрипты** — в папках `ozon/scripts/` и `wb/scripts/` для каждого маркетплейса;
- **Десктопное приложение** (папка `application/`, PyQt/PySide) — GUI-оболочка для выбора клиента и запуска отчётов без работы с Python.

---

## Технологии

- **Python 3.11+**
- `requests` — обращение к API маркетплейсов
- `pandas`, `openpyxl` — обработка данных и формирование Excel-отчётов
- `PyQt`/`PySide` — десктопное приложение
- `pyinstaller` — сборка приложения в `.exe`

```

│   ├── Clients/{client_name}/  #   данные и отчёты клиентов Ozon
│   └── scripts/                #   скрипты и модули Ozon
```

### Папки клиента `{marketplace}/Clients/{client_name}/`

Для каждого клиента хранятся:
- `catalog/` — справочная таблица клиента (себестоимость и характеристики товаров);
- `Actions/` — отчёты по акциям;
- `CampaignsReport/` — отчёты по рекламным кампаниям;
- `FinanceReports/` — отчёты по начислениям и маржинальности;
- `Metrics/` — метрики;
- `OrdersSvod/`, `SalesOrdersSvod/` — своды по заказам и продажам;
- `SupplySvod/` — свод по поставкам;
- `UploadFiles/` — выгруженные данные.

Структура папок для нового клиента создаётся автоматически.

## Перечень отчётов

Одни и те же отчёты реализованы для Ozon и для WB.

| Отчёт | Назначение |
|-------|-----------|
| **Выгрузка данных** | предварительная выгрузка данных за период (даты или «N дней назад») |
| **Планирование поставок** | планирование поставок на указанную дату (по данным выгрузки) |
| **Отчёт по акциям** | участие товаров в акциях |
| **Свод по заказам** | сводная по заказам за период |
| **Свод по заказам и продажам** | сводная по заказам и продажам |
| **Отчёт по РК** | статистика по рекламным кампаниям за период |
| **Отчёт маржинальности** | маржинальность за период |

## Быстрый старт

1. Клонировать репозиторий.
2. Установить зависимости:

   ```shell
   pip install -r requirements.txt
   ```

3. Создать файл настроек из шаблона:

   ```shell
   copy settings_example.json settings.json
   ```

   и заполнить данные клиентов (имя, русское название, API-ключи). [Схема полей](#файл-настроек-settingsjson).

4. Создать файл выбора клиента из шаблона:

   ```shell
   copy options_example.py options.py
   ```

   и указать номер магазина (`client_number`, нумерация с 0).

5. Запустить нужный скрипт, например выгрузку данных и свод по поставкам:

   ```shell
   python ozon/scripts/uploadDataFromOzon.py
   python ozon/scripts/create_supply_svod.py
   ```

Номер клиента также можно передать через переменную окружения `marketplace_client` или аргумент командной строки `-c N` / `--client N` (аргумент имеет приоритет над окружением, окружение — над значением в `options.py`).

## Файл настроек `settings.json`

Главный конфигурационный файл в корне проекта. Каждое поле — **список** (массив); для добавления клиента данные дописываются через запятую в каждый список. Наличие всех полей не обязательно (например, у клиента может быть только Ozon — тогда `api_key_wb` пустой).

```json
{
    "client_name": ["Example_Client"],
    "client_ru_name": ["Русское имя клиента"],
    "api_key_ozon": ["api_key_ozon"],
    "client_id_ozon": ["1"],
    "client_id_performance_ozon": ["1"],
    "client_secret_performance_ozon": ["client_secret"],
    "api_key_wb": ["api_key_wb"]
}
```

- `client_name` — имя клиента (используется в названии папки и файлов отчётов);
- `client_ru_name` — русское название клиента (для GUI);
- `api_key_ozon` — API-ключ **Seller API Ozon**;
- `client_id_ozon` — **Client ID** Seller API Ozon (в заголовках запросов);
- `client_id_performance_ozon` — **Client ID** Performance API Ozon;
- `client_secret_performance_ozon` — **Client Secret** Performance API Ozon (в заголовках запросов);
- `api_key_wb` — API-ключ Wildberries.

> Важно: следи за валидным JSON — после последнего элемента списка/словаря запятая не ставится.

## Справочная таблица клиента

Для формирования большинства отчётов обязательно наличие справочной таблицы клиента — данных по товарам, которые нельзя получить через API (например, себестоимость). Совпадение названий столбцов обязательно.

**Ozon** (минимальный набор полей):
`SKU`, `Артикул продавца`, `Наименование товара`, `РРЦ`, `Минимальная цена расчетная, руб.`, `Себестоимость`

**WB** (минимальный набор полей):
`Артикул WB`, `Артикул продавца`, `Наименование товара`, `РРЦ`, `Минимальная цена расчетная, руб.`, `Себестоимость`

Справочная таблица всегда должна лежать по пути:

```
{marketplace}/Clients/{client_name}/catalog/Справочная_таблица_{client_name}_{marketplace}.xlsx
```

Например: `ozon/Clients/Example_Client/catalog/Справочная_таблица_Example_Client_Ozon.xlsx`.

## Десктопное приложение

`application/main_window.py` — GUI на PyQt/PySide поверх скриптов: пользователь выбирает клиента, задаёт параметры отчёта и запускает формирование. Одна вкладка = один клиент, есть переключение светлой/тёмной темы, окно логов и статусы формирования отчёта («Формируется…», «Готово», «Сформирован с предупреждениями», «Ошибка»). Сборка в `.exe` — `application/build_app.bat` (PyInstaller, см. `.spec` в корне).

---

## Логирование

Логи ведётся через модули-логгеры (`custom_loggers.py`, `ozon_logger.py`, `wb_logger.py`) и пишутся в папку `logs/` по маркетплейсам и клиентам.
