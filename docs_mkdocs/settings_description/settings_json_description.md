# Заполнение файла настроек settings.json

Файл `settings.json` имеет следующую структуру:

``` json
{
    "client_name": [
        "Example_Client"
    ],
    "api_key_ozon": [
        "example_api_key_ozon"
    ],
    "client_id_ozon": [
        "1"
    ],
    "client_id_performance_ozon": [
        "1"
    ],
    "client_secret_performance_ozon": [
        "example_client_secret_performance_ozon"
    ],
    "api_key_wb": [
        "example_api_key_wb"
    ]
}
```

В нем присутствуют следующие поля:
- `client_name` - имя клиента, которое будет использоваться в названии папки клиента и в названиях файлов всех формируемых отчетов
- `api_key_ozon` - API-ключ Seller API Ozon
- `client_id_ozon` - Client ID для Seller API Ozon (передается в заголовках запросов)
- `client_id_performance_ozon` - Client ID для Performance API Ozon
- `client_secret_performance_ozon` - Client Secret для Performance API Ozon (передается в заголовках запросов)
- `api_key_wb` - API-ключ Wildberries

При необходимости добавить нового клиента, в соответствующие поля конфигурационного файла нужно через запятую добавить данные для нового клиента. Наличие всех полей не обязательно.
*Например, бывают ситуации, когда клиент предоставил доступ только к кабинету на маркетплейсе Ozon. Тогда поле* `api_key_wb` *будет пустым.*

**Важно учитывать форматирование json:**
Например, после последнего элемента списка или словаря запятая не ставится:
```json
"client_name": [
    "Client_1",
    "Client_2" // Правильно
]
```
```json
"client_name": [
    "Client_1",
    "Client_2", // Неправильно!
]
```

P.S. *Хранение конфиденциальной информации (по типу API-ключей) в файле внутри проекта (json, csv или в любом другом) **крайне не рекомендуется!**
Подобные данные следует хранить в переменных окружения или в другом защищенном месте.
На данный момент это является серьезной недоработкой данного проекта и является потенциальным риском кражи конфиденциальной информации.*

P.P.S. *Я знаю, что в json нельзя оставлять комментарии. Я это сделал для того, чтобы подчеркнуть место, где была допущена ошибка.*
