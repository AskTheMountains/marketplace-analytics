В файле `options.py` происходит парсинг файла настроек `settings.json` и выбор магазина, для которого будет производиться запуск всех скриптов.

Выбор магазина определяется переменной `client_number`.

**Важно**: нумерация магазинов начинается с 0. То есть, первый магазин в `settings.json` будет иметь номер 0.
